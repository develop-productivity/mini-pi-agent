# 做成 npm workspaces monorepo

2026-10-24 · 用户拍板 · 生效

**决定**：源码按层拆成 `packages/ai`、`packages/agent`（以后加 `packages/coding-agent`），用 npm workspaces 管理，包直接导出 TS 源码，不加构建步骤。

**为什么**
- 三层架构在目录上分开，层之间只能通过包的公开入口引用，依赖方向一眼能看出来。
- 不换包管理器、不加构建，学习成本最低。

设计见 [2026-10-24-monorepo.md](../designs/2026-10-24-monorepo.md)。
